# Keyboard shortcuts

Shortcuts work with any keyboard layout. On macOS use **Cmd** where it says **Ctrl**.

## Everywhere

| Keys | Action |
|---|---|
| **Ctrl+K** | Quick connect: find a host or a section, or lock |
| **Enter** | Submit a dialog |
| **Esc** | Close a dialog or menu |

## Terminal

| Keys | Action |
|---|---|
| **Ctrl+Shift+C** | Copy the selection |
| **Ctrl+Shift+V** | Paste |
| **Ctrl+C** | Copy the selection, or interrupt if nothing is selected (system terminal mode only) |
| **Ctrl+V** | Paste (system terminal mode only) |
| **Ctrl+Shift+F** | Find in the scrollback |
| **Enter** / **Shift+Enter** | Next / previous match while finding |
| **Ctrl+Shift+D** | Split right |
| **Ctrl+Shift+E** | Split down |
| **Enter** | Reconnect after the connection closed |

See [Terminal](/projects/detour/wiki/everyday/terminal) for the two copy and paste modes.

## Files

| Keys | Action |
|---|---|
| **Enter** | Open the folder, or download the selection |
| **Backspace** | Up one folder |
| **↑** / **↓**, **Home** / **End** | Move through the list |
| **Shift+↑** / **Shift+↓** | Extend the selection |
| **Ctrl+A** | Select all |
| **Esc** | Clear the selection |
| **F2** | Rename |
| **Del** | Delete |
| **F5** | Refresh |
| **Ctrl+L** | Type a path |

## Lists

| Keys | Action |
|---|---|
| **Del** | Delete the selected host (with **Undo**) |
| **Ctrl+Enter** | Save a snippet while editing its command |
