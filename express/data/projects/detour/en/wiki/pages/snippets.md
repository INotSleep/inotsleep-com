# Snippets

A snippet is a saved command with a name, for things you run often on different servers.

![Snippets](/api/projects/detour/assets/snippets.png)

## Create

Open **Snippets**, click **New snippet**, enter a **Name** and the **Command**. Commands can be several lines and use `&&`, pipes and anything else your shell understands. **Ctrl+Enter** saves.

## Run

Click **Run** on a snippet and pick a host. Detour opens a new terminal on that host and runs the command there. Unreachable hosts are marked in the list.

## Edit or delete

Use the **⋯** menu on a snippet. Deleting shows **Undo** for a few seconds.

In a [team](/projects/detour/wiki/sync-and-teams/teams), snippets are shared like hosts: everyone with **View** access can run them, and **Edit** access lets a member change them.
