# Detour

Detour is an open-source SSH client for Windows, macOS and Linux. On top of the usual terminal, SFTP and tunnels, it lets a team share hosts, keys and passwords through a Git repository or a folder the team already has. Everything is encrypted end to end, and there is no Detour server or account.
